# 坦克大战 · Tank Battle

一个使用纯 **HTML + CSS + JavaScript**（Canvas）编写的浏览器坦克大战游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制你的坦克，**保卫基地**，消灭每一关的所有敌人。
- 敌人会从顶部三个出生点源源不断地出现，越往后关卡敌人越强、越多。
- 基地一旦被击毁则游戏结束（经典规则）；你的坦克有 3 条命。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `方向键` | 移动 |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `M` | 开关音效 |
| `R` | 重新开始 |
| `回车` | 开始 / 继续 |

移动端会自动显示屏幕按钮。

## 游戏元素

- 🧱 **砖墙**：可被炮弹摧毁
- 🔩 **钢板**：不可摧毁，炮弹会被弹开
- 🌊 **水域**：坦克无法通行，炮弹可以穿过
- 🌿 **草丛**：坦克可以通行，且会被隐藏
- 🏠 **基地**：需要重点保护的目标

### 敌人类型

| 类型 | 颜色 | 特点 | 分值 |
| --- | --- | --- | --- |
| 普通 | 红 | 标准 | 100 |
| 快速 | 蓝 | 移动快 | 200 |
| 重型 | 紫 | 需要两发炮弹 | 400 |

### 道具（摧毁特殊敌人后掉落）

| 道具 | 效果 |
| --- | --- |
| ★ | 增加一条命 |
| ◇ | 护盾（短暂无敌） |
| ❄ | 冻结所有敌人 |
| ✸ | 全屏消灭敌人 |
| ⚡ | 快速射击 |

## 运行

直接用浏览器打开 `index.html`，或在项目目录启动任意静态服务器，例如：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

也可以在线体验：[GitHub Pages](https://pages.github.com/)（开启 Pages 后即可）。
